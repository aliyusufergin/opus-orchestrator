# Cost is Quota; the wrapper caps concurrency, and Astra needs the user's word

Both sides run on subscriptions: Codex signs in with ChatGPT Plus and no API key, and Claude runs without extra usage. So what a Run spends is Quota of rolling usage-limit windows, not dollars. Routing therefore leans on GPT-6.1 Sol, with GPT-6 Luna for checkable mechanical or extraction work; per token their Quota costs relate to GPT-6 Astra as 1 : 20 : 100 (Luna : Sol : Astra), and the measured basis is in [model routing data](../research/openai-model-routing-data.md). The wrapper allows at most three concurrent Delegations. The Orchestrator uses Astra only when the user allowed it when starting the Run, because Astra costs 2.5× Opus per token, Plus allows only 5–45 Astra messages per five hours, and it is the user's own Codex default, so Delegations would compete with the user's interactive use. That Astra rule is deliberately a prose rule in the skill, not an invariant in code: the user chose simplicity over enforcement, and every Astra Delegation shows in the Run record and the final report. When the ChatGPT Quota runs out, the Orchestrator stops delegating and asks the user once instead of finishing the work itself silently, which would spend the Claude Quota the Run exists to protect.

## Considered Options

- An OpenAI API key with per-token billing, which OpenAI recommends for automation: deferred, to revisit if Plus limits bind or ChatGPT sign-in tokens break under concurrent processes.
- Astra freely available to the Orchestrator's routing judgment: rejected because one fan-out can exhaust the five-hour window.
- Enforcing the Astra permission with hooks: a prompt hook would record `--allow-astra` from the user's invocation and a pre-tool hook would deny unallowed Astra Delegations. This is feasible, because deny decisions hold in every permission mode while "ask" is ignored in auto mode, and skill shell injection never sees the user's arguments. Rejected by the user in favour of a simpler plugin; revisit if the Run records show Astra used without permission.
- Silent fallback to Opus on any Codex failure: rejected for the reason above. A single failed Delegation is still the Orchestrator's call: retry once on a cheaper model or do the work itself, and say so in the report.
